# Port notes: VexFlow 5.7.0 → 5.8.0

Upstream range: `git -C ../vexflow log 5.7.0..5.8.0` (12 commits; release notes: `changelog/CHANGELOG.md`, section 5.8.0).
44 files in `src/` changed (+2627/-355). Seven modules are new. The manifest (`docs/porting-5.x-manifest.md`) gives the Swift file for each upstream file.

## New modules

- `dashpattern.ts` → `Rendering/DashPattern.swift`: `validateDashPattern(_:)`, `dashStops(_:_:)`. A pattern must be finite, nonnegative and contain a positive length. A line can have at most 16 384 segments (`MAX_DASH_SEGMENTS`, internal). Errors: `VexError("BadDashPattern")`.
- `renderer.ts` (`drawDashedLine` only) → `Rendering/Renderer.swift`: `enum Renderer` with `static func drawDashedLine(...) throws`. The path is planned before the context changes. A line with a nonfinite length throws `BadDashLine`. `TextBracket` and `StringNumber` now use it (`StringNumber` had a private copy of the old algorithm).
- `flaredhairpin.ts` → `Stave/FlaredHairpin.swift`: `HairpinPoint`, `drawFlaredHairpin(_:_:_:_:)`.
- `automaticaccidentals.ts` → internal flag `Accidental.isAutomatic` (upstream: a module `WeakSet`). `Policies.swift` sets it on each generated sign.
- `figuredbass.ts` → `Modifiers/FiguredBass.swift`: `FiguredBass`, `FiguredBassSpec`, `FiguredBassFigure`, `getInkParts()`. Rows have independent continuation lines. `VexCategory.figuredBass`, `Factory.FiguredBass(_:) throws`, `measureEngraving` includes the ink parts.
- `tabtiefit.ts` → `Layout/TabTieFit.swift`: `fitTabTie(_:_:_:)`.
- `easyscore/independentmeter.ts` → `API/EasyScore/IndependentMeter.swift`: `independentMeterGrid`, `initialStaffState`, `InteriorBar`, `MeterPosition`.
- `publicationcondense.ts` → `Publication/PublicationCondense.swift`: `PublicationCondense(players:measures:name:)`; `condenseStaves`, `markCondensedPlayers` (internal).
- `publicationcue.ts` → `Publication/PublicationCue.swift`: `CueTransposition(semitones:steps:)`, `CueBuilder` (a `Builder` subclass), `writtenCue` (internal).

## Changes to existing modules

Rendering safeguards:
- `SVGRenderContext` (commit 3e847e36): the old check rejected `on*` and `href` names. It now also rejects `style`, every `*:href` name, and compares lowercased names, as upstream `isUnsafeAttributeName`. Shadows: upstream now sets `path.style.filter` instead of a `style` attribute. The browser serializes this as `style="filter: drop-shadow(<color> 0px 0px <blur>px);"` (color first, `rgb()` colors, 6 significant digits, attribute last). Swift writes the same string, so the shadow cases match the 5.9.0 references.
- Beam slope fitting (commit 73461bff), ported exactly: `maxSlopeIterations = 1000`, the `beamSlopes` loop, `minCost = .infinity`, the clamped start slope and the bounds checks. New `BeamError.badSlopeIterations` / `.badSlopeBounds`. `calculateSlope()` throws.

Expression:
- `Curve`: `CurveOptions.halfDashed`; `PhraseRibbon`: `drawHalfDashedSlur(_:_:_:dash:)` and De Casteljau `splitBezier` at any `t`.
- `StaveTie`: dashed ties on selected heads; laissez-vibrer ties per chord head (`TieNotes.laissezVibrer`, `StaveTieError.invalidLaissezVibrer`, `Factory.StaveTie(laissezVibrer:)`).
- `StaveHairpin`: `HairpinRenderOptions.flared`. `TextDynamics` accepts `n` (timed niente).
- `Beam`: French beams (`BeamRenderOptions.frenchBeams`, `BeamConfig.frenchBeams`, `EasyScoreAutoBeamOptions.frenchBeams`, `Factory.Beam(frenchBeams:)`); `Stem.adjustHeightForBeam(_ inset:)`. `ContinuousBeam` needs no change: Swift copies the full render options.
- `Ornament`: parenthesized turns (`setParenthesized(_:)`), pitched trills (`setAuxiliaryPitch(_:) throws`, ledger lines for the cue note), `Factory.Ornament(auxiliaryPitch:parenthesized:)`, `Factory.OrnamentThrowing`.

Notation:
- `Barline`/`BarNote`: `BarlineType.dashed` (8), `.dotted` (9), `.doubleHeavy` (10). See "Double heavy barline" below.
- `Clef`/`ClefNote`: `ClefAnnotation.doubleOctaveUp`/`.doubleOctaveDown` (`15ma`/`15mb`), ink bounds of these glyphs, wider inline clef.
- `Accidental`: bracketed editorial accidentals (`AccidentalEnclosure`, `setAsCautionary(_ enclosure:)`, `enclosure`); generated signs share one sign at a unison (`isShared`).
- `Modifier.getAttachedLine()`; `FretHandFinger` (`setDrawCircle(_:)`, TAB placement beside the fret) and `StringNumber` (TAB notes accepted, `clearRect` at the left and right of a fret); `TabNote.getFretInk()`; `FretDiagram` chord-frame fingering (`FretDiagramSpec.fingerings`, `setFingerings(_:)`).
- `PhraseLayout`: stanza labels (`PhraseVerseOptions.stanza`, `getStanzaColumnWidth(_:)`, `PhraseLayoutError.invalidStanza`); `System.format` reserves the stanza column.

Rhythm and parts:
- `Composition`: independent meters (`ContinuousOptions.independentMeters`), cross-measure tuplets (`ContinuousOptions.tuplets: [ContinuousTuplet]`), `EasyScoreVerse(stanza:syllables:)` (`EasyScoreMeasureSpec.verses` is `[EasyScoreVerse]`; an array literal still builds one), `EasyScoreComposition.meterPositions` and `getMeterPosition(_:)`.
- `Policies`: voices are `[[Tickable]]`, the stave is optional.
- `ContinuousLayout`/`ContinuousSpan`: `flared`, `wavy` (`drawWavyGlissando`), `halfDashed`, `dashed` spans with their validation; TAB tie side fitting with the fret ink; interior bars; justification weighted by the window ticks with independent meters; `resolveTabTie` no longer sets a default side (`spanAbove` gives it).
- `Sheet.alignToMeasures(_:)` (internal, upstream `@internal`) and the fixed-width row path.
- `Publication`/`PublicationView`: multi-measure ossias (`PublicationRegion.endMeasure`) split at host system breaks (one caption, `data-end-measure`), transposed cues (`PublicationRegion.transpose`, key-aware accidentals), condensed conductor staves (`PublicationView.condense`, `PublicationOptions.condense`), semantic events with meter positions, continuous tuplets kept in parts.

## Double heavy barline (local VexFlowPatch)

Upstream 5.8.0 has the same type with the same names (`DOUBLE_HEAVY`, type string `doubleHeavy`). The upstream implementation replaces the local patch. The Swift name `.doubleHeavy` and the string `"doubleHeavy"` do not change, so no alias is necessary and callers compile. Differences from the old local version:
- The raw value is 10 (was 8). A stored raw value 8 now reads as `.dashed`. No code in the repository uses `BarlineType(rawValue:)`.
- The two 3 px strokes are at `x - 7` and `x - 2` (were `x - 5` and `x`): 2 px to the left, with the right edge at `x + 1`, as for the end bar.
- Modifier width 8 (was 5); layout metrics `xMin: -7` (was `-5`); a `BarNote` of this type is 17 px wide (was 0).
`docs/local-deviations.md` records this.

## Swift deviations

- Registries: `automaticAccidentals` is `Accidental.isAutomatic`; `meterPositions` is keyed by `ObjectIdentifier`.
- `Beam.postFormat()` does not throw. A bad slope option is kept in `Beam.slopeError`; `draw()` throws it. `slopeIterations` is an `Int`.
- Non-throwing APIs: a bad laissez vibrer sets `initError` (an ordinary partial tie); `TextBracket.setDashed` ignores an invalid pattern (`setDashedThrowing` throws); `Factory.Ornament` drops a bad pitch (`OrnamentThrowing` throws); a transposition error in `CueBuilder` sets `commitError`.
- `Modifier.getAttachedLine()` is public and throws (no `protected` in Swift). `FretHandFinger.format` wraps a new `formatThrowing`.
- `FiguredBass.getBoundingBox()` returns `nil` when the layout is not valid (upstream throws).
- `PhraseLayout.draw` throws (stanza labels use `drawWithStyle`). `addVerse(options: PhraseLaneOptions)` stays as an overload.
- `PublicationCondense.players` is `[String]` and `.measures` is `[Int]?` (upstream tuples); the same checks apply. Region metadata lists keys in declaration order, so `scale` and `transpose` appear when they are set.
- Integer types make some upstream rejections impossible (`numNotes: 2.5`, `endMeasure: 2.5`, fractional slope iterations, `[3, , 1]` sparse dash arrays, unknown policy strings).

## Not ported

- DOM and canvas setup of `Renderer`; browser ink measurement in publication (the native `SVGNode`/`svgInkBox` code is used).
- The SVG-versus-Canvas equality checks in the node tests (no Canvas backend).
- `tests/scores/*.js` viewer scores (saints, electric, quartertones, fugue viewer text), as in earlier releases. The demo data that the parity cases use is ported (see below).

## Parity

5.8.0 has no reference SVGs; the 5.9.0 references are the oracle.
