# Port notes: VexFlow 5.1.0 → 5.2.0

Upstream range: `git -C ../vexflow log 5.1.0..5.2.0` (release notes: `changelog/CHANGELOG.md`, sections 5.1.1, 5.1.2 and 5.2.0).

## Ported

### New modules
- `src/proportionalformatter.ts` → `Formatting/ProportionalFormatter.swift`. Strict musical-time spacing: `ProportionalSpacing(pixelsPerQuarter:)`, `FormatterOptions.spacing`, `SystemFormatterOptions.spacing`. Errors are `VexError` with the upstream codes (`BadArgument`, `InsufficientProportionalSpace`) and messages.
- `src/chordkerning.ts` → `Modifiers/ChordKerning.swift`: `ChordSymbolPosition`, `ChordSymbolKerningPair`, `ChordSymbolKerningProfile`, `ChordSymbolText`, `ChordSymbolRun`, `chordKerningProfile(_:custom:)`, `layoutChordRuns(...)`.
- `src/easyscore/*` → `API/EasyScore/`: `ElementIndex.swift` (score-local IDs and `EasyScoreSource`), `Elements.swift` (`EasyScoreElements`, the `make` helpers), `Rhythm.swift` (`EasyScoreAutoBeamOptions`, auto beaming), `Policies.swift` (key-aware accidentals), `Composition.swift` (`compose`).
- `src/textmetricscache.ts`: `TextMeasurer` already has a bounded cache that is cleared when the font registry generation changes. Added `VexElement.clearTextMeasurementCache()`; `Metrics.clear()` also clears the cache.

### Behavior changes in existing modules
- `StemmableNote`: `isAutoStem()`, `setStemDirection(_:autoStem:)`. `StaveNote.autoStem()`, the voice-collision code in `StaveNote.format` and `Beam` keep the automatic flag.
- `Beam`: `BeamConfig.stemPolicy` (`BeamStemPolicy.auto/.explicit/.preserve`); `Beam(autoStem: true)` keeps notes automatic.
- `EasyScore.beam(_:autoStem:)`: the default is now `nil` (upstream `undefined`): automatic stems are resolved for the whole group and explicit stems are respected. Before, the default was `false`.
- `Formatter`: proportional path in `preCalculateMinTotalWidth`, `createModifierContexts` (ignored ticks do not advance), `createTickContexts`, `preFormat`, `tune` (no-op), `postFormat`.
- `ChordSymbol`: `setKerning(_:)` (`ChordSymbolKerning.auto/.none`, default `.none`), `setKerningProfile(_:) throws`, `kernedRuns`, kerned draw and bounding box, right alignment with kerned runs. An empty chord symbol now has an empty bounding box (was `nil`).
- `Articulation.parseEasyScore(_:) throws`: aliases (`fermata`, `marcato`, `staccatissimo`), native codes, SMuFL glyph names, position suffixes. Unknown names throw. `easyScoreHook` now throws.
- `Element`: `setAttributeThrowing(_:_:)` runs score-local ID validators; `setAttribute` ignores a rejected ID. `onRegister(_:)` takes `Registry?`.
- `Registry.transaction(_:)`, `getRegisteredElements()`.
- `Parser`: `ParseResult.furthestErrorPos`; `Rule.runState` receives `TriggerState(matches:start:end:)`.
- `Factory`: ownership (`Factory.getOwner`, `Factory.getGroup`), `adopt(_:role:)`, `transaction(_:)`, `groupNotes(_:_:)`, `FactoryElementRole`, new constructors (`Bend`, `Clef`, `KeySignature`, `TimeSignature`, `Barline`, `Repetition`, `Volta`, `StaveSection`, `StaveTempo`, `StaveText`, `TabTie`, `TabSlide`, `GraceTabNote`, `Dot`, `Parenthesis`, `Stroke`, `Tremolo`, `Vibrato`, `Crescendo`, `StaveHairpin`), `TabNote(_:drawStem:)`, `KeySigNote(...clef:)`. `TextBracket`/`VibratoBracket` apply an explicit `line: 0`. Accessors `getRenderQueue()`, `getSystems()`, `getSheets()`.
- `KeySignature.setClef(_:)` (`clefOverride`), `KeySigNote(...clef:)`, `Stave` `StaveOptions.clef` and clef tracking in `addModifier`, `Clef.getType()`.
- `ClefNote.getBoundingBox()` uses the stave line. `StaveNote.getBoundingBox(includeModifiers:)`. `Sheet` vertical bounds use layout-only boxes.
- `Tuplet`: an explicit `yOffset`/`textYOffset` of 0 is kept.
- `Tickable.clearVoice()`, `Note.clearStave()`, `Accidental.isCautionary()`. `Dot`/`Parenthesis.setNote` copy `fontInfo`.

### New EasyScore API
`EasyScore.create(options:scoreOptions:runtimeContext:)`, `make`, `attach(_:_:index:)`, `attachToStave(_:_:position:)`, `adopt(_:role:)`, `getElement(_:)`, `getNote(_:)`, `getSource(_:)`, `EasyScore.getSource(_:)`, `build(_:)`, `withDefaults(clef:time:stem:_:)`, `set(clef:time:stem:)`, `compose(_:)`, `system(_:)`, `sheet(_:)`, `sequence(_:options:)`, `autoBeam(_:options:)`, `parseNotation(_:options:)`, `voice(_:options:)`/`voiceThrowing(_:options:)` (`EasyScoreVoiceOptions`), `setStyle(_:)`, `draw(retain:)`, `reset()`, `lastError`. Types: `EasyScoreError`, `EasyScoreDiagnostic`, `EasyScoreSourceSpan`, `EasyScoreParsedPiece`, `EasyScoreParseResult`, `EasyScoreValidationContext`, `EasyScoreSequenceItem`, and the composition spec types. `EasyScoreOptions` has `strictOptions`, `extensions`, `validate`. `Builder` is `open`; subclasses override `commitPiece(source:)`. `CommitHook` can throw.

## Swift deviations
- Builder options stay `[String: String]`: typed upstream options are strings (`"octaveShift": "1"`, `"durationOverride": "1/2"`).
- Source offsets count `Character`s (upstream: UTF-16 code units). They are the same for ASCII input.
- Upstream monkey-patchable or untyped inputs are typed: hairpin type (`HairpinType`), stave modifier position (`StaveModifierPosition`), kerning mode, tab slide direction (`TieDirection`). Those upstream validation errors cannot occur.
- `EasyScore.create` always sets `throwOnError` and `strictOptions` (upstream lets `scoreOptions` override them).
- Non-throwing methods (`notes`, `parse`, `beam`, `tuplet`, `voice`) record the error in `lastError`; use the `…Throwing` variants for the upstream exceptions. A legacy (non-strict) `parse` with a throwing hook returns an unsuccessful result instead of throwing.
- Element ownership (`factoryOwner`) is a strong reference, as the values of the upstream `WeakMap`. Grace-group membership is weak.
- `EasyScore.make` returns a new helper each time, which keeps the score alive (Swift has no garbage collector).

## Not ported (reason)
- `TextMetricsCache` browser keys (canvas `direction`, `lang`, `letterSpacing`, ...) and `FontFaceSet` listeners, `Font.load` cache clearing, `Element.setTextMeasurementCanvas`: no DOM or canvas. CoreText measurement is keyed by font and text, and the font registry generation clears it.
- User guide, Explorer, `tools/*` (example renderers, API audit, coverage manifest), release tooling: browser and build only.

## Tests
- `Tests/VexFoundationTests/Upstream52Tests.swift` (72 tests in 7 suites): proportional spacing, chord kerning, metrics, beam stem policy, core changes, EasyScore contracts, EasyScore rendering (native vs EasyScore SVG output, retained redraw).
- New parity cases: `Beam.Auto_stemmed_tuplets_across_middle_line`, `Formatter.Strict_proportional_spacing`.
- Skipped upstream assertions:
  - metrics-tests: canvas mock cache keys, LRU capacity, `FontFaceSet` events, `Font.load` (browser canvas). Only record isolation and cache clearing are ported.
  - chord-kerning-tests: Canvas vs SVG `fillText` call comparison (SVG only).
  - proportional-spacing-tests: the Canvas back end of the System test (SVG only).
  - easyscore-tests: coverage manifest and API audit tests (docs/tools), `BrokenModifier`/`RefusingNote` (Swift `getNote()`/`addModifier()` cannot be overridden to throw), frozen option objects and validator copy mutation (value types), `adopt(null)`, non-integer indexes, stave position 99, async `build` (type system), `textDynamics` `durationOverride` (no such `TextNoteStruct` field), `tie(from: annotation)` (type-checked).
  - easyscore-rendering-tests: pixel screenshots, Canvas back end, draw-count instrumentation (replaced by SVG output equality), the families/rhythm/structure/composition renderers from `tools/`.
  - tool-security-tests.mjs (release tooling), tests/easyscore_types.ts (TypeScript compile-time checks).
- No unit test changed: `swift test --scratch-path .build-port --skip UpstreamSVGParityTests` passes (917 tests, 3 known issues from before).
