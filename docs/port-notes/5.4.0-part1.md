# Port notes: VexFlow 5.3.0 → 5.4.0, part 1

Upstream range: `git -C ../vexflow log 5.3.0..5.4.0` (release notes: `changelog/CHANGELOG.md`, section 5.4.0).
This pass ports the changes to existing modules and the phrase, instrument and spelling modules. Part 2 ports the continuous layout, the breaks, the publication and the score navigation. The hooks that part 2 must connect are listed at the end of this file.

### Changes to existing modules
- `Note`: `NotationIdentity` (kinds `unpitched`, `technique`, `harmony`, `tuning`, `tremolo`, `accidental`), `NoteStruct.notation`, `Note.notation`. Also `StaveNoteStruct.notation`, `TabNoteStruct.notation` and `GraceNoteStruct.notation`.
- `StaveNote` and `TabNote`: attach the guitar gestures of `notation` at construction; the SVG note group gets `aria-label` with the identity labels.
- `Annotation`: `phraseManaged`, `setConnectorPadding(_:) throws` (counted on both sides in `format`), `getTextBaseline()`, `setLayoutBaseline(_:)` (an authored `textBaseline` wins).
- `Articulation.setLayoutShiftY(_:)`, `Ornament.setLayoutShiftY(_:)`.
- `Beam.getStripBounds()`.
- `Bend`: `PREBEND`, `HOLD`, `Bend.timed(_:) throws` (rise, hold and release at exact fractions of the width), the release after a prebend or hold.
- `Clef.getInkBounds() throws`, `TimeSignature.getInkBounds() throws` (shared `topBaseline`), `KeySignature.setOrdered(_:) throws`, `KeySignature.getInkParts()` (formats again when the stave moved).
- `Curve`: `setLayoutRise(_:)` (added to both control points), `hasManualControls()`, `getNotes()`, `getRouteParts() throws`.
- `StaveTie`: `setLayoutRise(_:)`, `hasManualControls()`, `getRouteParts() throws`.
- `PedalMarking`: `getNotes()`, `setLayoutBaseline(_:)`, `getBoundingBox()`.
- `StaveHairpin`: `getNotes()`, `setLayoutBaseline(_:_:_:)`, `getLayoutEdges() throws -> LayoutEdges`, `getBoundingBox()`; `renderHairpin` and `draw` use the shared edges.
- `TextBracket`: `setLayoutBaseline(_:)`, `getBoundingBox()` (shared `geometry()`). The gated VexFlowPatch (no backward bracket) stays in `draw`.
- `measureEngraving`: `PedalMarking`, `StaveHairpin` and `TextBracket` participate through `getBoundingBox()`.
- `Stave`: `StaveOptions.barlineSpan` (`StaveBarlineSpan`), `getBarlineBounds() throws`, `setBoundaryModifiers(_:)` (joined in `getModifiers`, drawn, and a courtesy end clef is returned by `getEndClef()`). `Barline` uses the barline bounds, and the repeat dots use the span.
- `StaveConnector`: the `bracket` type honors `xShift`.
- `Stroke`: an explicit `noteEnd` extends the stroke.
- `Tuplet`: phrase-managed annotations do not move the bracket.
- `Voice.preserveStaveAssignments`.
- `System`: `getPhraseLayout()`, `format(row:)`/`formatThrowing(row:)` with `SystemRowLayout` (`staffOffsets`, `endPadding`), `getBoundingBox()` merges the phrase bounds, `draw()` draws the lyric connectors.
- `Sheet`: the vertical bounds start at the system envelope (so phrase bounds above the system count).
- EasyScore: `EasyScoreMeasureSpec.instrument` (`EasyScoreInstrumentName`), `EasyScoreStaveSpec.name`/`shortName`; `applyCompositionAccidentals` reports each generated accidental to an optional `placed` closure.
- `Flow` facade header updated. The new classes are module types, as in earlier releases.

## Swift deviations
- The guitar, fret-diagram and percussion inputs use enums and tuples (`GuitarStroke.Finger/Direction/Arrows`, `GesturePhase`, `FrettedPosition`, `FretDiagramString`, `PercussionInstrument.Head/Stem`). The upstream checks for invalid strings cannot fail, so `strokeIdentity` does not throw.
- An invalid timed bend in `notation` sets `Note.initError = .invalidNotation`; a TAB bend on a string outside the chord sets `TabNote.tabInitError = .invalidNotation` (upstream throws from the constructor). Use `TabNote(validating:)` to throw.
- `CurveOptions(cps:)` takes an optional; `authoredControls` is true when the caller passes `cps` (upstream `options.cps !== undefined`).
- `PhraseLayout.pin(_:)` takes any `VexElement` (upstream: articulation, ornament, stave note, curve or tie). `PhraseLayout.format` does not throw; `measureEngraving` only throws for invalid padding, which the layout never passes.
- `PhraseDiagnostic.sources` uses `""` for an element without an `id` (upstream `undefined`).
- `PedalMarking.getBoundingBox()` keeps the existing Swift `noteEndX` (with the VexFlowPatch pedal styles); upstream renamed it `releaseX`.

## Not ported (reason)
- `src/font.ts`: `FontLoadFailed` wraps a browser `FontFace` load failure. VexFoundation loads bundled fonts (`Flow.loadFonts` already throws `FontRegistryError.resourceNotFound`).
- Part 2 modules: `continuouslayout.ts`, `continuousspan.ts`, `systembreaks.ts`, `pagebreaks.ts`, `publication.ts`, `publicationview.ts`, `scorenavigation.ts`.
- Tests that need a browser or Part 2: `tests/node/continuous-score-tests.mjs`, `tests/node/publication-tests.mjs`, the publication, `getBBox` and gallery parts of `instrument-profile-tests.mjs`, the puppeteer test of `phrase-layout-tests.mjs`, `tests/web/*`, `tests/engraving/*` studies (the `phrase-studies.mjs` choir and piano scenes are rebuilt in the Swift tests).
