# Port notes: VexFlow 5.0.0 → 5.1.0

Upstream range: `git -C ../vexflow log 5.0.0..5.1.0` (release notes: `changelog/CHANGELOG.md`, section 5.1.0).
Most of the 5,900-line `src` diff only adds the TypeScript `override` keyword. The behavioral changes are listed below.

## Ported

### New modules
- `src/sheet.ts` → `Layout/Sheet.swift`: `Sheet`, `SheetOptions`, `SheetRow`. `Factory.Sheet(options:)`, `Sheet.addSystem(_:)`, `setWidth(_:)` (throws), `getWidth()`, `getSystems()`, `getRows()`, `getHeight()`, `format()` (throws).
- `src/svgexport.ts` → `Rendering/SVGExport.swift`: `svgWithFontPaths(_:)`, `svgPathData(_:decimalPlaces:)`, `SVGRenderContext.toSVG(portable:)` and `static toSVG(_:portable:includeXMLHeader:)`, `SVGExportError`.
  Upstream takes opentype.js fonts. The Swift version takes outlines from the same CoreText fonts that laid out the score (`TextMeasurer.layout(...).path(x:y:)`), so no font list is necessary. Each `<text>` becomes a `<path>` with the same non-font attributes; the live drawing does not change. A `.notdef` glyph throws `SVGExportError.missingFont`.
- `textmetricscache.ts` is not in this range (it is 5.2.0). `TextMeasurer` already has a cache that is cleared when the font registry generation changes. No change.

### Metrics and fonts
- `Metrics.defaults` matches the 5.1.0 `MetricsDefaults` (`pointerRect`, `textFontFamily`, `isText` keys, `StaveNote.pointerRect`, `Tuplet.pointerRect/bracket/suffix`).
- `MetricsStore.getFontInfo` uses the text-font family for `isText` keys (port of `Metrics.getFontFamily`).
- `VexFont.TEXT_FONT_NAMES`, `VexRuntimeContext.setTextFonts/getTextFonts`, `Flow.setTextFonts/getTextFonts`. `setFonts` now splits comma lists and selects the text stack.
- `TextNote` uses `TextNote.text` metrics (upstream typo `TexNote.subSuper` fixed).

### Element, styles, render context
- `RenderContext.setDefaultStyle(_:)` / `getDefaultStyle()` (protocol requirements with a default side-table implementation; `SVGRenderContext` and `SwiftUICanvasContext` store them).
- `VexElement.styleExplicit`, `shouldDrawPointerRect`, `drawPointerRect()`, score-default stripping in `applyStyle`, inherited defaults in `drawWithStyle`, `setOriginX/Y` fix (articulation draw idempotence). `shadowBlur`/`lineWidth`/`lineDash` are applied when set (also 0 / empty).
- `setFontSize(_ size: String)` is now `open` (overridden by `TabNote`).
- `openGroup` class names include the element `class` attribute, and `drawPointerRect()` runs before `closeGroup()` in all files that upstream changed.
- `Factory.setStyle(_:)`, `getStyle()`, `draw(retain:)`; `Stave` ledger-line default style; `PedalMarking`/`TextBracket` `renderOptions.color` is now `String?` (default `nil`, inherits); `StaveLine` and `PedalMarking` apply the element style; `StringNumber` no longer forces black lines.

### Durations, key signatures, notes
- Maxima (`1/8`, `m`), longa (`1/4`, `l`), 512th and 1024th durations: `Tables`, `NoteValue` (`.maxima`, `.longa`, `.fiveTwelfth`, `.oneThousandTwentyFourth`), stem lengths, beam durations, rest glyphs/shifts.
- `flats_N` / `sharps_N` (N = 0…14) and `Dbm`, `Gbm`, `G#`, `D#`, `A#`. More than 7 accidentals gives double accidentals.
- `Tables.noteHeadStemYOffsets`, `StaveNote.getStemYBounds()` (stems attach to SMuFL anchors on X noteheads).
- `StaveNote`: rest clearance (`shiftRestVertical`), owned noteheads replaced on rebuild, bounding box from layout coordinates (before draw), shared flag position, ties use `ModifierContext.getRightShiftForTie()`. The constructor no longer calls `reset()`/`buildFlag()` a second time (auto IDs change).
- `Note.parseDuration` / `durationToken(of:)`: strict anchored regex and a 64-character limit.

### Tuplets, voices, formatting
- `Tickable`: `addTuplet`, `removeTuplet` (throws), `clearTuplets`, `setTupletStack`; `setTuplet` replaces; `resetTuplet` is deprecated; `tupletStack` is read-only; `getTuplet()` returns the last tuplet; duration edits invalidate the voice.
- `Voice.invalidateTicks()` with lazy recount; `Voice.validate(_:)`, `parseTime(_:)`, `init(validating:)`, `init(parsingTime:)`.
- `Tuplet`: `suffix` option and `suffixElement`, metrics-driven bracket geometry, `getBoundingBox()`, new `getNestedTupletCount()`.
- `ModifierContext`: annotations above/below a note do not push nearby modifiers; `annotationRightShift`, `getRightShiftForTie()`.
- `Annotation.computeX()`, `computeY()`, `setTextBaseline(_:)` (throws), `getVerticalJustification()`.
- `PedalMarking.getYForStave(_:)` (clears bottom annotations).
- `Formatter` changes are a refactor only (no behavior change).

### Bounding boxes
`Curve.getBoundingBox()` (bezier extrema), `TimeSignature.getBoundingBox()` (+ `topRenderY`/`botRenderY`), `Stroke.getBoundingBox()`, `GraceNoteGroup.getBoundingBox()` (positions the grace notes, no draw required), `TextDynamics.getBoundingBox()`.

### Other
- `Barline` `RepeatBracketType` (`.none`, `.straight`, `.curved`), `setRepeatBracket`, `drawStraightBrackets`, `drawCurvedBrackets`; `Stave.setBegBarType/setEndBarType(_:repeatBracket:)`.
- `System.setWidth(_:)` (override), `setWidth()` (auto), `setWidthThrowing(_:)`, `getWidth()`.
- `EasyScore.measures(_:options:)` (throws); `Builder` option `duration`.
- `TabNote.setFontSize` / `fretFontSize`; fret text scales with the grace scale and is centered with `(ascent - descent) / 2`.
- `Registry.isValidIndexName(_:)`; unknown index names are ignored.
- `Fraction.setThrowing(_:_:)`.

## Not ported (reason)
- `svgcontext.ts` `resize()` writes `px` CSS sizes: the Swift serializer has no DOM `style` attribute.
- `util.ts` `structuredClone` ponyfill, `canvascontext.ts` formatting, `index.ts` exports, explorer/demos: browser or build only. `VexFlow.Sheet` / `RepeatBracketType` are module types in Swift.
- Registry prototype-key protection: Swift dictionaries are not affected. Unknown index names are ignored instead of throwing (the Swift methods do not throw).
- `Fraction` finite checks: `Int` values are always finite; only the zero-denominator check is added, as `setThrowing`.
- `Voice(time:)` / `Voice(time: String)` keep their non-throwing behavior and fall back to 4/4 for an invalid meter; the new throwing initializers match upstream.
- `Tuning.setTuning` and `Accidental.applyAccidentals` sorting: the Swift code already had the 5.1.0 behavior.

## Parity against 5.0.0 references (intended differences)
Baseline: 0 row mismatches, about 102 cases over 0.1 px. After the port: 45 row mismatches, about 411 cases over 0.1 px. All changes compared with the previous Swift output were classified:
- Pointer rectangles (`rect` rows only, 123 cases): the StaveNote box now uses layout coordinates; `GraceNote` has no pointer rect (category `GraceNote` gets `pointerRect: false`), which causes all 45 row mismatches (Grace_Notes, Accidental.Automatic_Accidentals, Percussion_Snare2/3, Strokes arpeggio); Stroke boxes no longer stretch notes to the origin.
- Text font (114 text-only cases, plus mixed cases): text elements use `Academico,Bravura` (Petaluma: `Petaluma Script,Petaluma`), so text widths and positions change (Annotation, Bend, ChordSymbol, Stave text, TextBracket, PedalMarking text, TextNote). Tab fret digits move up 0.168 px (new `yShift`), and grace tab frets are 6 pt.
- Paths: stems of X noteheads (Percussion, NoteHead, Rhythm scratches, StaveNote harmonic/muted, EasyScore muted), rest clearance (Three_Voice_Rests), and bracket lengths that follow text widths.
