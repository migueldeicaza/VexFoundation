# Port notes: VexFlow 5.8.0 → 5.9.0 (final upstream release)

Upstream range: `git -C ../vexflow log 5.8.0..5.9.0` (10 commits; release notes: `changelog/CHANGELOG.md`, section 5.9.0).
32 files in `src/` changed (+1469/-118). Ten modules are new. The work was done in two parallel worktrees ("instruments" and "early notation") and merged into this tree.

Build info: `Compatibility/Version.swift` now reports `5.9.0`, commit `136e78e2ae8619bb275cc42d91fdd39b8767526f` (tag `5.9.0`), date `2026-11-21T20:30:15-05:00`. Upstream `version.ts` itself did not change (build-time placeholders).

Instruments (`Instruments/`):

- `flutefingering.ts` → `FluteFingering.swift`: `FluteKey`, `FluteKeyState`, `FluteTrillKey`, `FluteFingering`.

Early notation:

- `chantphrase.ts` → `Stave/ChantPhrase.swift`: `ChantPhrase`, `ChantSyllable`, `ChantPhraseOptions`, `ChantPhraseRow`, `ChantGroupPlacement`, `ChantNeumeKind`.
- `frenchlutenote.ts` → `Tablature/FrenchLuteNote.swift`: `FrenchLuteNote(validating:drawStem:)`, `Factory.FrenchLuteNote(_:drawStem:) throws`.
- `germanlutenote.ts` → `Tablature/GermanLuteNote.swift`: `GermanLuteNote`, `GermanLuteNoteStruct`, `getInkParts()`, `Factory.GermanLuteNote(_:) throws`.
- `kievannote.ts` → `Notes/KievanNote.swift`: `KievanNote`, `KievanNoteStruct`, `Factory.KievanNote(_:) throws`.

`VexCategory`/TypeGuard: `FrenchLuteNote`, `GermanLuteNote`, `KievanNote`. `AccordionRegister` keeps the Annotation category, as upstream. The `VexFlow.*` facade entries are module types (`Flow.swift` header lists them).

## Changes to existing modules

Guitar and banjo:
- `Tuning`: half-step-down `eb` now ends on `Eb/3` (commit 5afbd674). Nut frets (`Tuning.nutFrets`, `init(_:nutFrets:)`); `standardBanjo` has a short fifth string with its nut at fret 5; fret lookups take `capo:`. New `TuningError` cases `.invalidNutFrets`, `.invalidCapo`, `.fretBelowNut`. The local 4.x tunings `doubleCBanjo`, `doubleDBanjo` and `sawmillBanjo` are kept (upstream does not have them); they keep full-length fifth strings.
- `FrettedInstrument`: passes the capo to the tuning instead of adding it to the fret.
- `FretDiagram`: horizontal (rotated) frames (`FretDiagramOrientation`, `FretDiagramSpec.orientation`) and `lookupVoicing(_:tuning:name:) throws`.
- `TabNote`: `clearFretLines`, `createFretElement(_:)`, `getFretLine(_:)` (hooks for the lute notes).

Instrument parts:
- `GraceNoteGroup`: `highland(_:pitches:) throws` with `HighlandEmbellishment`, and `getHighlandName()`.
- `Sheet`: `addStickingLine(_:) throws` (`StickingAssignment`, `StickingHand`) and `alignSticking(_:)`; `ContinuousLayout` aligns the sticking line in each row.
- `Annotation`: `getLayoutHeight()` drives format and `computeY`. The class is no longer `final` so that the instrument signs can subclass it.
- `Tuplet`: the clearance above or below annotations uses `getTextInk`.
- `EngravingGeometry`: `FluteFingering`, `AccordionRegister`, `HarpPedalDiagram` use the annotation branch; new `KievanNote` and `GermanLuteNote` branches.

Pitch and early notation:
- `KeySignature`/`KeySigNote`: custom signatures by written pitch and clef (`OrderedKeySign`, `setOrdered(_:)`; the old tuple overload is kept) and edition presets (`KeySignaturePresets.register/select`, makam signatures).
- `StaveNote`: `StaveNoteStruct.whiteMensural` (white maxima, longa and brevis signs; `StaveNoteError.invalidWhiteMensural`) and `StaveNote.applyFourShape(_:_:)` (movable four-shape heads by scale degree, re-chosen on stem reversal).
- `TimeSignature`/`TimeSignatureSpec`: four `TimeSignatureSymbol.mensural*` signs.
- `Clef`/`ClefName`/`Tables`: `kievan`, `chant-c`, `chant-f` clefs and line shifts. Maxima and longa durations were already in `Tables`.
- `StaveConnector`/`System`: Mensurstriche (`ConnectorType.mensurstrich`, raw value 9), `System.addMensurstriche()`, `System.addConnectorThrowing(type:)`, `System.setOptions(_:)`.

Text measurement (parity fix, not an upstream change): `TextMeasurer` measures a Unicode space that the first font lacks (for example U+2002 in the harp change label) the way HarfBuzz/Chromium does (`hb_ot_shape_fallback_spaces`: an en space is half an em). Without it the harp label was 2.95 px short in all fonts. No other source or test text uses these characters.

## Swift deviations

- New range errors use `VexError("RangeError", …)` or typed errors; throwing factory methods.
- `getBoundingBox()` of the instrument signs returns `nil` when the sign is not attached and formatted (upstream throws).
- `Tuning.init(_:nutFrets:)` is a separate initializer: a defaulted `nutFrets` made `Tuning()` resolve to the failable `init?(parsingOrNil:)`.
- `FrenchLuteNote` uses the label `validating:` (a throwing initializer cannot override `TabNote`'s). It sets `clearFretLines = false` in its initializer.
- The non-throwing `addConnector(type: .mensurstrich)` with a staff count other than two returns a `.none` connector; `addConnectorThrowing` throws as upstream.
- A bad `whiteMensural` note records an init error; `StaveNote(validating:)` throws.
- `ChantStave` with no options has no barlines; explicit options are used as given, with four lines.
- Swift enums and integer types make some upstream rejections impossible (non-boolean ranks, unknown key names, fractional courses and frets).

## Not ported

- SVG-versus-Canvas checks and the Canvas pixel-ink count of the horizontal-frame test (no Canvas backend).
- `rendering-tests.mjs` change: a jsdom PNG count.
- Flute aria-labels are checked by searching the SVG output (no `querySelector`).
- The guide, feature catalog and report pages of the release (documentation site only).

- `swift test --scratch-path .build-port --skip UpstreamSVGParityTests`: 1106 tests pass (3 known issues, as before).

## Parity

See `docs/parity-status-5.9.0.md`. 495 cases (was 480): every `svg_*` case of the 5.9.0 reference set has a parity case, and there is no "Missing upstream reference". No ROWS mismatches; the 8 STRUCT mismatches are the old Gonville missing-glyph cases. No existing case changed. The 15 new cases match within 0.1 px in every font that has the glyphs (Bravura all within 0.01). The six new runs over 0.1 px are missing glyphs: Petaluma and Gonville German lute, Petaluma and Gonville accordion, Gonville four-shape notes and Gonville Sabâ flat.
